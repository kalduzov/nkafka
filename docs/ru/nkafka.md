# NKafka

[English](../en/nkafka.md)

NKafka — клиентская библиотека .NET для Apache Kafka. Она предназначена для отправки и чтения сообщений и интеграции с приложениями .NET. Ниже описана целевая архитектура; готовность возможностей следует проверять по соответствующим спецификациям и тестам.

## Кластер

Кластер — центральный компонент и точка входа для работы с Kafka. Приложение может независимо управлять несколькими кластерами. После подключения из кластера можно создавать продюсеров и потребителей.

Кластер также предоставляет административные операции: создание и удаление тем, управление списками контроля доступа.

Закрытие кластера освобождает его внутренние ресурсы и транспортные соединения. Зависящие от него клиенты после этого не могут продолжать штатную работу.

Конфигурация кластера содержит параметры подключения, безопасности, версий протокола, обнаружения брокеров и обновления топологии. Созданные клиенты используют этот общий контекст подключения на протяжении своего времени жизни.

## Пул соединений

Архитектура NKafka предусматривает общие соединения с брокерами на уровне кластера, чтобы не создавать лишние соединения для каждого продюсера. Для работы с кластером Kafka могут потребоваться соединения с несколькими брокерами; совместное использование не означает обращения ко всем брокерам через один сокет. Выделенные соединения потребителей используются там, где это необходимо модели взаимодействия клиента.

Общие ресурсы предназначены для уменьшения расходов на соединения. Сетевой уровень ориентирован на сокетные события и ограниченное количество рабочих потоков либо пул потоков .NET вместо создания лишних потоков. Это архитектурные цели, а не результаты измеренного сравнения производительности с другими клиентами.
